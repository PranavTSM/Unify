  USER ACTION: Open app and view message with AI insights

  1. Browser → http://localhost:3000
     ↓

     ↓
  3. Dashboard.jsx fetches:
     → GET /unified/inbox
     → GET /unified/calendar
     ↓
  4. Aggregator orchestrates:
     → Calls MCP → External APIs
     → Normalizes, merges, scores
     → Returns unified data
     ↓
  5. User sees:
     ✓ 1,284 total messages
     ✓ 23 unread
     ✓ Recent 5 messages
     ✓ Today's 3 events
     ↓
  6. User clicks message → "View Full Details"
     ↓
  7. ViewDetails.jsx calls:
     → POST /unified/inbox/summarize
     → POST /unified/inbox/extract-actions
     ↓
  8. Aggregator → LLM Service → OpenAI
     ↓
  9. AI generates:
     ✓ Summary: "This message discusses..."
     ✓ Key points: ["Point 1", "Point 2", "Point 3"]
     ✓ Actions: [{desc: "...", priority: "high", due: "..."}]
     ↓
  10. User sees AI insights in 2-3 seconds! 🤖
