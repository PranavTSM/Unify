1️⃣  MCP SERVER (Port 8000)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Role: Backend API Gateway
  
  Connects To:
    → Google APIs (Gmail, Calendar) via OAuth2
    → Microsoft Graph (Outlook, Teams) via MSAL
  
  What It Does:
    ✓ Authenticates with external services
    ✓ Fetches raw Gmail messages
    ✓ Fetches raw Outlook emails
    ✓ Fetches raw Teams messages
    ✓ Fetches calendar events
    ✓ Returns raw JSON data
  
  Key Endpoints:
    GET /gmail/messages
    GET /outlook/messages
    GET /teams/messages
    GET /calendars/{id}/events
    GET /health
  
  Environment:
    GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET
    MSFT_CLIENT_ID, MSFT_CLIENT_SECRET


2️⃣  AGGREGATOR (Port 8001)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Role: Central Orchestration Hub
  
  Connects To:
    → MCP Server (fetches raw data)
    → LLM Service (requests AI processing)
  
  What It Does:
    ✓ Fetches from all sources via MCP
    ✓ Normalizes different formats to unified schema
    ✓ Merges & deduplicates messages (YOUR FIX!)
    ✓ Calculates importance scores
    ✓ Detects calendar conflicts
    ✓ Calls LLM for AI features
  
  Key Components:
    • UnifiedAggregator - Fetches data
    • Normalizers - Convert formats
    • Merger - Deduplicate & sort
    • Scorer - Calculate importance
    • LLMServiceClient - AI integration
  
  Key Endpoints:
    GET  /unified/inbox             - Aggregated data
    GET  /unified/calendar          - Calendar events
    POST /unified/inbox/summarize   - AI summaries ⭐
    POST /unified/inbox/extract-actions - AI actions ⭐
  
  Environment:
    MCP_SERVER_URL=http://mcp_server:8000
    LLM_SERVICE_URL=http://llm_service:8002


3️⃣  LLM SERVICE (Port 8002)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Role: AI Processing Engine
  
  Connects To:
    → OpenAI API (text processing)
    → Qdrant (vector storage)
    → Redis (conversation memory)
  
  What It Does:
    ✓ Summarizes messages (3 modes)
    ✓ Extracts action items
    ✓ Generates embeddings
    ✓ Stores in semantic memory (Qdrant)
    ✓ Tracks conversations (Redis)
    ✓ Retrieves context for queries
  
  Key Components:
    • Summarizer - Text summarization
    • ActionExtractor - Task extraction
    • EmbeddingsManager - Qdrant interface
    • RedisMemory - Conversation tracking
    • UnifiedRetriever - Context retrieval
  
  Key Endpoints:
    POST /summarize-batch    - Batch summarization
    POST /extract-actions    - Action extraction
    POST /store              - Store in memory
    GET  /context            - Retrieve context
    GET  /memory/status      - Memory health
  
  Environment:
    OPENAI_API_KEY=sk-...
    QDRANT_URL=http://qdrant:6333
    REDIS_URL=redis://redis:6379


🔄 COMPLETE DATA FLOW EXAMPLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

User Request: "Summarize my inbox"
  ↓
1. POST /unified/inbox/summarize → Aggregator
  ↓
2. Aggregator checks LLM health
   GET llm_service:8002/health
  ↓
3. Aggregator fetches messages
   GET mcp_server:8000/gmail/messages
   GET mcp_server:8000/outlook/messages
   GET mcp_server:8000/teams/messages
  ↓
4. MCP Server calls External APIs
   → Gmail API: users().messages().list()
   → Graph API: GET /me/messages
   → Graph API: GET /teams/messages
  ↓
5. MCP returns raw JSON → Aggregator
  ↓
6. Aggregator processes:
   • Normalize formats
   • Merge & deduplicate (YOUR FIX!)
   • Calculate scores
  ↓
7. Aggregator → LLM Service
   POST llm_service:8002/summarize-batch
   {messages: [...]}
  ↓
8. LLM Service processes:
   • Flatten messages to text
   • Call OpenAI GPT-3.5
   • Generate summary
   • Store in Qdrant/Redis (optional)
  ↓
9. LLM returns summary → Aggregator
  ↓
10. Aggregator formats response
  ↓
User receives: AI-powered summary! 🎉
