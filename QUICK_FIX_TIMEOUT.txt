================================================================================
QUICK FIX: Timeout Errors & No Messages
================================================================================

PROBLEM:
You're seeing timeout errors like:
  "ERROR: HTTPConnectionPool: Read timed out"
  "No messages from optimized endpoint"
  "No Gmail/Outlook/Teams messages found"

ROOT CAUSE:
The MCP Server (port 8000) is either:
  1. Not running
  2. Hanging/not responding
  3. Not authenticated

================================================================================
SOLUTION:
================================================================================

STEP 1: CHECK IF MCP SERVER IS RUNNING
---------------------------------------
Run: python check_mcp_server.py

Or manually check:
  curl http://localhost:8000/health

If you get "Connection refused" → MCP server is NOT running!

STEP 2: START MCP SERVER
-------------------------
Open a NEW terminal/command prompt:

  cd mcp_server
  python app.py

You should see:
  ✅ Uvicorn running on http://0.0.0.0:8000
  ✅ Application startup complete

STEP 3: AUTHENTICATE
--------------------
Open browser and visit:

For Gmail:
  http://localhost:8000/google/auth

For Outlook/Teams:
  http://localhost:8000/msgraph/auth

Follow the OAuth flow and grant permissions.

STEP 4: RESTART AGGREGATOR
---------------------------
Stop and restart the aggregator:
  
  Ctrl+C (to stop)
  python app.py (to restart)

STEP 5: TEST
------------
Refresh your browser at http://localhost:5173

Messages should now load!

================================================================================
QUICK CHECK (Windows):
================================================================================

Run: fix_services.bat

This will:
  ✓ Check all services
  ✓ Show which are running
  ✓ Tell you what to fix

================================================================================
COMMON ISSUES:
================================================================================

Issue: "Port 8000 already in use"
Fix: Kill the process using port 8000
     netstat -ano | findstr :8000
     taskkill /PID <PID> /F

Issue: "Module not found"
Fix: Install dependencies
     cd mcp_server
     pip install -r requirements.txt

Issue: "Auth failed"
Fix: Check your .env file has correct credentials
     GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET
     OUT_CLIENT_ID, OUT_CLIENT_SECRET

Issue: "Still timing out"
Fix: 1. Check firewall/antivirus
     2. Try localhost vs 127.0.0.1
     3. Check MCP server logs for errors
