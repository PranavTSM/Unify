🎯 WHAT EACH SERVICE DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 1. FRONTEND (Port 3000)
 ─────────────────────────
    • React 18 + Vite + Tailwind CSS
    • 4 Pages: Dashboard, Inbox, ViewDetails, Calendar
    • Real-time data display
    • AI-powered insights
    • Auto-refresh (30s/60s)
    • Search & filter
    • Professional UI/UX

    Talks to: Aggregator (8001)
    
    Features:
      ✓ Shows unified inbox
      ✓ Displays calendar events
      ✓ AI summaries
      ✓ Action extraction
      ✓ Loading/error states


 2. AGGREGATOR (Port 8001) ⭐ MAIN API
 ────────────────────────────────────
    • FastAPI Python service
    • Central orchestration hub
    • Normalizes all data formats
    • Merges & deduplicates
    • Calculates importance scores
    • Routes AI requests

    Talks to: MCP Server (8000), LLM Service (8002)
    
    Provides to Frontend:
      GET  /unified/inbox           → Unified messages
      GET  /unified/calendar        → Calendar events
      POST /unified/inbox/summarize → AI summaries
      POST /unified/inbox/extract-actions → AI actions
    
    Features:
      ✓ Data aggregation
      ✓ Deduplication
      ✓ Importance scoring
      ✓ AI routing
      ✓ CORS enabled


 3. LLM SERVICE (Port 8002)
 ──────────────────────────
    • FastAPI + LangChain + OpenAI
    • AI processing engine
    • Memory system (Qdrant + Redis)
    
    Talks to: OpenAI API, Qdrant, Redis
    
    Provides:
      POST /summarize-batch     → Generate summaries
      POST /extract-actions     → Extract action items
      POST /store               → Store in memory
      GET  /context             → Retrieve context
    
    Features:
      ✓ Text summarization (3 modes)
      ✓ Action item extraction
      ✓ Priority scoring
      ✓ Vector embeddings
      ✓ Conversation tracking


 4. MCP SERVER (Port 8000)
 ─────────────────────────
    • FastAPI service
    • Backend API gateway
    • OAuth2 authentication
    
    Talks to: Gmail API, MS Graph API
    
    Provides:
      GET /gmail/messages
      GET /outlook/messages
      GET /teams/messages
      GET /calendars/{id}/events
    
    Features:
      ✓ Google OAuth2
      ✓ MS Graph OAuth2
      ✓ Token management
      ✓ Raw data fetching


 5. QDRANT (Port 6333)
 ─────────────────────
    • Vector database
    • Semantic search
    • Stores message embeddings
    
    Used by: LLM Service
    
    Features:
      ✓ 1536-dim vectors
      ✓ Cosine similarity search
      ✓ Metadata filtering
      ✓ Long-term memory


 6. REDIS (Port 6379)
 ────────────────────
    • In-memory cache
    • Conversation storage
    • Session management
    
    Used by: LLM Service
    
    Features:
      ✓ 24-hour TTL
      ✓ Chat history
      ✓ Fast access
      ✓ Persistence
